# MythicPlusPageExtension

> 史诗钥石地下城界面扩展工具（Mythic+ 页面增强）
> 作者：CN2714

本插件用于增强游戏内的大秘境（史诗钥石地下城）界面，替代大秘境玩家常用的两个主要 WA：每周大秘境追踪（Weekly Mythic+ Tracker）、史诗钥石地下城界面增强（分数 + 传送 + 通报），并提供队伍钥石查看、队伍信息展示与大秘境周报等功能。

## 功能特性

### 1. 大秘境界面增强（分数 / 传送 / 通报）
- 在大秘境页面的副本图标处显示该副本的**最高评分**与**最高通关层数**。
- **点击副本图标即可直接使用副本传送门**，悬停可查看传送门可用状态与剩余冷却时间。
- 使用传送门后，可选择**通报到队伍 / 团队频道**（可设置发送时机：开始传送 / 传送完成）。
- 分数文本颜色样式可选：跟随最高层、RaiderIO 风格、标准风格。
- 提供启用/禁用、清理副本图标上其他插件的非原生内容、原版样式（WA 风格）等详细选项。

### 2. 大秘境周报
- 打开大秘境页面时自动显示当周大秘境统计周报窗口。
- 周报内容：**宝库奖励对应等级**、**本周 Top 8 最佳记录**、**各副本总通关次数与各次层数**。
- 可自定义字体大小、窗口宽度与高度校正，并可选择隐藏 RaiderIO 框架。

### 3. 队伍信息与钥石共享
- 展示队友的基础信息（装等、职业、专精）与**副本记录**（最佳通关层数 / 分数）。
- 自动在队伍内**共享钥石信息**，方便快速查看队友钥石。

## 使用说明

### 大秘境界面增强
- 打开**地下城和团队副本**功能（快捷键：I），切换到**史诗钥石地下城**即可看到本插件提供的功能。

### /命令支持
- 打开设置面板： /mppe
